# CodeBase AI — GitHub Repository Intelligence Platform
- A full-stack RAG application enabling developers to authenticate with GitHub and interact with public/private repositories using natural language. 
- Implemented OAuth2 authentication, asynchronous repository indexing, semantic code search using pgvector, and context-aware AI chat using Spring AI.

## Tech Stack :-

- Java 17 
- Spring Boot 
- Spring Security 
- OAuth2
- Spring AI 
- PostgreSQL 
- pgvector
- Next.js 
- TypeScript
- Shadcn UI 
- Docker
